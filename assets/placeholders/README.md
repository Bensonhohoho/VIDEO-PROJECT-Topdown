# Placeholder Assets

These assets are temporary UI placeholders. Replace the referenced texture files
in the scene inspector when final drink and reward art is ready.

- `soda_icon.svg`: drink buff icon.
- `res://scenes/floating_score_text.tscn`: score gain visual effect.
- `res://scenes/QueueNPCPlaceholder.tscn`: queue NPC placeholder scene.
- `res://scenes/game.tscn` / `EventMapPlaceholders`: map objects and
  interactable prop placeholders kept in the main scene for later replacement.
